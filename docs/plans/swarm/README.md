# Swarm design campaign archive

This directory groups the older root-level `swarm-*.md` design documents that were
previously scattered directly under `docs/`.

These files are **plans/reviews from a design campaign**, not a declaration that the
current first-party swarm implementation still follows every historical decision.
For current swarm/session-control work, prefer the active
[`../swarm-port-plan/`](../swarm-port-plan/) material and current source.

The documents remain together because they cross-reference one another heavily.
