# Hosted multi-tenant task results

This directory stores implementation evidence for
`../tasks/00-INDEX.md`.

Each task writes `Txx.md` using the result format defined in
`../tasks/AGENTS.md`.

Result files are not status theater. A PASS requires the task's explicit exit
criteria, commands, evidence, changed paths, commits, deviations, and remaining
risks.

T18 treats missing or stale mandatory results as open gates.
