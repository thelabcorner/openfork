# Gate P UX specification

## 1. Navigation

Parent activities are a special external-agent timeline, visually related to chat
Sessions but not mixed semantically into the Session tree.

Recommended sidebar section:

```text
CHATGPT / OXP

  ChatGPT OXP · opencode
  42 calls · 2 workers · now

  OXP architecture implementation
  118 calls · 5 workers · 3h
```

Each row consumes only `OxpParentSummary`.

## 2. Detail route

Preferred global route:

```text
/oxp/activity/:activityID
```

Header:

```text
ChatGPT / OXP
External parent Q7F2A9

First seen       5:31 PM
Last activity    now
Observed epochs  3
Tool calls       118
Failures         4
Workers created  5
Roots touched    3
```

There is no composer.

## 3. Timeline row

One invocation card represents one span:

```text
5:41:15 PM  PATCH
4 files · /opencode
31 ms
Committed
```

Expanded detail:

```text
Invocation
  ID             oxpi_...
  Plane          augmentation
  Tool           patch
  Started        5:41:15.105
  Completed      5:41:15.136
  Duration       31 ms

Authority context
  Root           /opencode

Outcome
  Mutation       committed

Links
  ...
```

Do not present persisted grant snapshots as if they were current authority.

## 4. Timeline markers

Non-invocation markers include:

- new observed epoch;
- 20-minute continuity advisory;
- host observation restart;
- local rename/archive.

Example:

```text
──────── Continuity ────────
Observed epoch reached handoff threshold.
Durable worker continuation already established.
```

## 5. Concurrency

Default list remains chronological, but overlapping calls get an overlap indicator.

An optional compact burst view may render:

```text
5:41:02  read A  ─────────┐
5:41:02  read B  ─────┐   │
5:41:03  find C  ─────────────┐
```

Do not force overlapping spans into fake request/response message ordering.

## 6. Filters

Initial filters:

- All
- Augmentation
- Supervision
- Delegation
- Mutations
- Errors
- Workers

Later:

- External MCP
- Files
- root alias
- safe-summary search

## 7. Discovery density

Low-value discovery calls may collapse:

```text
Capability discovery · 3 calls
```

Mutation, worker, request-supervision, file-transfer, and failure rows remain
prominent.

## 8. Resource navigation

Native resource link examples:

```text
Delegated worker
ses_abc123
[Open Session]
```

The corresponding Session surface may show:

```text
Origin
ChatGPT / OXP
Parent activity Q7F2A9
[Open OXP Activity]
```

## 9. Rename/archive/delete

The activity may be renamed locally because OpenFork does not possess the upstream
ChatGPT conversation title.

Archive is presentation state.

Delete removes activity history only. It never deletes:

- Sessions/workers;
- tasks;
- files;
- commits;
- processes or process artifacts;
- external MCP resources.
