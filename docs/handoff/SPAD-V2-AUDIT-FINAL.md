SPAD-v2-FRONTIER-RESEARCH — final mathematical audit
Conventions: L=|w|; p is a period iff w[i]=w[i+p] for all i≤L−p; p* = minimal period; e=L/p*; W = window length at decision time.

1. Verified results
Runs Theorem (L44; A1/CP): ρ(n)<n runs and Σ e_r ≤ 3n−3; Lyndon-root characterization gives O(n) all-runs. Binary brute force n≤14, ternary n≤9: 0 violations. (Exact 3n−3 rests on theorem pointers; abstracts confirm <n and 3n only — see limitations.)
Fine–Wilf + sharp threshold (L57; A1/CP): if one word has periods p,q and L ≥ p+q−gcd(p,q), then gcd(p,q) is a period, and the bound is tight. For the plan's 96/192/288 example only (192,288)→96 is informative (96|192, 96|288 are automatic). Sharp witness: a¹⁹¹ b a¹⁹¹ (L=383) has periods 192 and 288 but not 96; L=384 is the first length forcing 96.
Minimal period / power / primitive root (L71, L319; A2/CR): p* = m−π_w[m−1]; borders are the π-iterates πʲ[m−1]; w=uᵏ (k≥2) iff p*|m and p*<m. Exhaustive binary n≤14: 0 violations.
Canonical cyclic identity (L85–91; A2/CR): κ(w)=minrot(root(w)) is a complete invariant of the cyclic class: κ(w)=κ(v) iff roots are conjugate; κ(ab)=κ(abab)=κ(baba).
Suffix automaton (L192; A2): append-only online, ≤2n−1 states, ≤3n−4 transitions, amortized O(1)/char, Θ(n) memory.
LPF novelty separation (L192–199; A2/CR): for eventually periodic x, LPF(i)/(|x|−i)→1; i.i.d. uniform σ, LPF(i)=Θ(log_σ i) a.s., so separation at i is Θ(i/log i).
Run object (L44, L320–331; A1/A2): a run is (i,j,p*) with e≥2 and no one-symbol extension preserving p*; abcab has e=5/3 and is not a run.
α-gapped repeats (L128, L134; A1/CP): uvu, |uv|≤α|u| ⇔ |v|≤(α−1)|u|; O(αn) maximal repeats (tight) and O(αn) algorithm on constant alphabets. Arm-domination |v|≤|u| holds iff α≤2.
k-period (L95–102; A3/CV): k-period p ⇔ HAM(S[1..W−p], S[p+1..W])≤k; compared=W−p. i.i.d. null: E[x_i]=1−Σπ² (≈0.9895 for σ=95), Cov(x_i,x_{i+p})=Var_a(π_a)≥0 → p-dependent, needs block CI.
No Fine–Wilf closure under mismatches (L320; A3/CV): "aaaaba" has p=2→1 mismatch, p=3→1, gcd=1→2 despite L≥p+q−g. Periods do not survive gcd under Hamming error.
Normalization is non-injective (L119; A3/CV): A–Z→a–z, whitespace collapse; the canonical witness cannot be lifted back to raw text without loss counters or raw re-verification; it also violates p-match's equal-length/identity-on-constants premises.
Parameterized matching (L140–149; A3/CV): t=f(s) bijective on parameters, identity on constants, iff pred(s)=pred(t). Evidence strength ∝ constant coverage and r (parameter classes occurring ≥2×); all-fresh parameters are wildcards (e.g. Attempt 1/2/3 failed p-matches). Adversarial FPs: f(A,B) vs f(B,A), guard/callee swaps.
Phase-0 current state (L697–704; A6/CL): verified against repo — experimental.spad_recovery:true required; raw exact recovery on; code-fence/canonical/expansion/persisted/tool/thrash off; reasoning observe-only (recovery branch dormant, enforced only at the processor call site); gym bun test test/session/spad-gym.test.ts = 6 pass / 0 fail / 559 expects, supervisor-level synthetic.
Auditor decision math (L411–541; A5/CS): τ = C_FP/(C_FP+C_FN) on p=P(degenerate|post-detector evidence). At TPR=.99, FPR=.01, π_F=.05: PPV=.83898 < τ=.98039, a ≈9.6× expected-loss increase.
