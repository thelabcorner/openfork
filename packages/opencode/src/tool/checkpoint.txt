Time-travel checkpoints. Every completed turn records the worktree. Restore
undoes filesystem only — never conversation, git index, or the user's commits.

Modes:
  list     this session's timeline (default). Footer counts OTHER sessions on
           this worktree. Pass across:"worktree" to see them.
  search   WHO touched a file — defaults to across:"worktree" (every session
           that shares this disk). Isolated worktrees are not listed.
  view     one checkpoint (ordinal in this/from session, or checkpointID)
  diff     turn (default) or cumulative in that checkpoint's session
  restore  THE UNDO BUTTON. Dry-run by default.

Cross-session (the thing that actually matters):
- Ordinals are PER SESSION. Session A's 3 is not session B's 3.
- To restore another agent's checkpoint: search → copy checkpointID →
  restore checkpointID:"…" (preview, then dryRun:false confirm:"RESTORE_CHECKPOINT").
- `from:"ses_…"` scopes list/view/diff to that session. Restore of a foreign
  row still requires checkpointID so an ordinal cannot silently jump chats.
- Restore rewrites the SHARED worktree. A pre-revert safety checkpoint is
  recorded on THIS session so you can undo.

Typical:
1. search touchedPath:"path/to/file.ts"
2. diff checkpointID:"…"
3. restore checkpointID:"…"  (preview) then again with dryRun:false confirm:"RESTORE_CHECKPOINT"
