- Search the web for discovery and current information; use web fetch after discovery when full page content is needed
- Provides up-to-date information for current events and recent data
- Supports configurable result counts; backends may return dense excerpts/page context or ranked snippets and URLs
- Use this tool for accessing information beyond knowledge cutoff
- Searches are performed automatically within a single API call

Providers (8): exa | parallel | firecrawl | duckduckgo | brave | tavily | searxng | ollama

Keyless out of the box (no API key required):
  - DuckDuckGo — keyless
  - Exa Web Search (mcp.exa.ai) — keyless; EXA_API_KEY optional to raise limits
  - Parallel Web Search (search.parallel.ai) — keyless; PARALLEL_API_KEY optional
  - Firecrawl Web Search (api.firecrawl.dev) — keyless where permitted; FIRECRAWL_API_KEY bypasses anonymous access restrictions

Key-based (free tiers) and self-hosted:
  - Brave Search — needs BRAVE_API_KEY (free tier: https://brave.com/search/api/)
  - Tavily Search — needs TAVILY_API_KEY (free tier: https://tavily.com)
  - Ollama Web Search — needs OLLAMA_API_KEY (free account: https://ollama.com/blog/web-search)
  - SearXNG — self-hosted; needs SEARXNG_URL (https://docs.searxng.org)

Introspection:
  - Run websearch({ action: "providers" }) to list every provider with its config status
     (keyless-ready | keyless-conditional | ready | needs <ENV_VAR>) and how to enable each — no query, no network.
  - The listing also shows a live cooldown when an anonymous backend recently denied this host
     (e.g. cooldown 287s after HTTP 403): process-local, expires on its own, and it never applies
     to strict provider pins or to configured credentials.

Provider selection:
  - Normally omit `provider`. Automatic search tries Parallel -> Exa -> Firecrawl -> configured SearXNG/Brave/Tavily/Ollama -> DuckDuckGo, falling through on errors or empty results.
  - Feature flags make an available provider a preference without disabling fallback.
  - The explicit `provider` parameter and OPENCODE_WEBSEARCH_PROVIDER are strict operational pins and intentionally disable fallback to other providers.
  - A flag does not substitute for required credentials: Brave/Tavily/Ollama require API keys and SearXNG requires SEARXNG_URL. Anonymous Firecrawl access can be denied by IP-based anti-abuse policy even though the keyless endpoint exists.

Usage notes:
  - Supports live crawling modes when available: 'fallback' (backup if cached unavailable) or 'preferred' (prioritize live crawling)
  - Search types when available: 'auto' (balanced), 'fast' (quick results), 'deep' (comprehensive search)
  - Configurable context length for optimal LLM integration
  - Provider-specific controls are normalized where supported; unsupported controls are ignored rather than invented.
  - Permission metadata shows the preferred automatic chain; result metadata records the provider that actually succeeded
  - Per-provider params: numResults applies to all; livecrawl/type/contextMaxCharacters are Exa-specific

The current year is {{year}}. Include it when it materially improves freshness, but do not mechanically append a year to every current-information query.
