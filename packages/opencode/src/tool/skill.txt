Load a specialized skill when the task matches a skill, including skills that are not in this project.

Use this tool to inject the skill's instructions and resources into the current conversation.

Where skills come from:
- Registered project/user skills (agent-skills/, skills/, .skills/, .opencode/skill, Claude/Codex folders, config paths).
- Anywhere on disk: Downloads, another repo, a USB path, etc. Pass filePath or a path-like name.

Load:
- skill({ name: "my-skill" }) — registered name (fuzzy: kebab/snake/case/partial).
- skill({ filePath: "~/Downloads/my-skill" }) — folder or SKILL.md outside the repo.
- skill({ name: "C:/Users/me/other-project/skills/foo/SKILL.md" }) — path in name also works.
- skill({ names: ["a", "~/Downloads/b"] }) — mix names and paths.

If the user explicitly provides a filesystem path but the requested skill is
sent by basename, a matching path from the request may be recovered;
otherwise always pass the full path in filePath or name. Paths are never
guessed by scanning the filesystem.

A path load parses the markdown, then keeps that skill available by its frontmatter name for the rest of this session.

Other modes:
- list — enumerate discovered + imported skills
- search — filter by query / tags

If a name is missing, the tool returns the available list and how to load from a path instead of dying.
