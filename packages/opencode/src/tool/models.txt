Search and inspect OpenFork's models with bounded, stable paging and machine-readable metadata. Default scope=configured queries the live configured provider catalog; scope=catalog queries public models.dev metadata (not proof of accessible credentials). action=list|get|providers; filter by providerID, case-insensitive q, reasoning/tools/vision, published-zero-cost, context and token prices; sort by relevance/name/provider/model/context/output/prices/release or observed usage. includeUsage=true adds the top 100 settled models over 30 days (historical/partial, never interpreted as zero when absent); use sort=usage for most-used models. includeQuota=true requires an exact providerID and performs only one advisory provider quota read; an exhausted observed window does not establish inference unavailability or resolve an account route. No secret headers, API keys, hidden account resolution, provider mutation, or inference. Pricing numbers are provider-reported metadata, not an estimate of entitlement. Prefer action=get with providerID+modelID for exact selection and use the native provider router to execute.
