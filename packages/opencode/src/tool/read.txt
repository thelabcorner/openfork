Read a file or directory. Prefer outline / pattern / symbol over paging.

Usage:
- filePath (or file_path): absolute path. filePaths[]: up to 8 files in one call.
- offset (1-indexed) + limit (default 2000). Offset past EOF clamps to the last page.
- action: read (default) | outline | grep | around | tail
- pattern: search this file (implies grep). Do NOT page looking for a name.
- symbol: jump to that definition (implies around).
- Call in parallel for known files. Avoid tiny 30-line slices.
- Unsure of the path? Use glob. Project-wide search? Use grep.
- Directories list entries (trailing /). Images/PDFs attach. Binary is rejected.
