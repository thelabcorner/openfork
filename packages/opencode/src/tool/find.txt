Find files or search file contents with ripgrep through one compact tool. Set exactly one of `glob` or `grep`: use `glob` for file/path patterns and `grep` for regex content search. `path` scopes either operation; `include` is a grep-only file filter. Prefer this over shell find/grep/rg for ordinary codebase discovery. Accepted fields are exactly `glob`, `grep`, `path`, and `include`; a `pattern` field is rejected — pass `grep` for content search or `glob` for paths.
