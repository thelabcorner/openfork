# OXP executable parity contract

Read the root/package `AGENTS.md`,
`docs/architecture/tool-surface-parity.md`, and
`docs/architecture/oxp-native-tool-parity.md` first.

- This folder adapts OpenFork capabilities for the external ChatGPT/OXP
  principal. A listed or described OXP capability is not parity unless
  its broker/direct/Session action actually invokes the authoritative leaf.
- All applicable new native/lazy/Code tools must receive an executable OXP
  disposition, or a narrowly reviewed, documented, tested exception.
  Preserve stable compact discovery and lazy schema loading.
- Enforce approved-root grants, real Session supervision or legitimate
  delegation, authorization at execution/egress, revocation, and output
  redaction/bounds. Never fabricate `Tool.Context` or borrow native secrets.
- Keep `oxp-native-tool-parity.md` and the OXP verifier current, but do not
  claim these OXP checks certify OFXP/ACP/MCP.
